Companion code repository for:

> **Towards Self-consistent Modeling of Quasi-Stars and their NLTE Spectra: Implications for Little Red Dots**
>
> Jake B. Hassan, Rosalba Perna, Mitchell C. Begelman, Yan-Fei Jiang, Matteo Cantiello, Philip J. Armitage, Taeho Ryu
>
> Submitted to ApJ

## Overview

This repository contains MESA files for the quasi-star models described in Hassan et al. (2026). The repository will be updated as improvements are found in the code.

A template for the fiducial model in the paper is provided in the "MESA model" folder. See Instructions.md for details on how to run it.
